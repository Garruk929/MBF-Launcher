# MBF Launcher — Pixel 9a

Launcher Android indipendente, ispirato alla navigazione di Niagara: indice A–Z laterale, app preferite, due layout Classic e Modern, temi chiaro/scuro, notifiche in alto con risposta rapida quando Android e l’app lo consentono.

## APK
GitHub → Actions → **Build MBF Launcher APK** → esecuzione riuscita → **Artifacts** → `MBF-Launcher-Pixel9a-debug`. Scarica e decomprimi il file ZIP sul Pixel 9a, quindi installa `app-debug.apk`. Concedi l’autorizzazione all’installazione da file se richiesta.

Poi vai in Impostazioni → App → App predefinite → App Home → MBF Launcher. Per mostrare e rispondere alle notifiche, apri la rotella nel launcher e concedi esplicitamente l’accesso alle notifiche.

Prima versione sperimentale: test sul Pixel 9a ancora necessari. Il launcher non sostituisce l'area notifiche di sistema o il blocco schermo.
